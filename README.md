# PacManProject

Проект "PacManProject" был разработан в рамках учебной программы [Яндекс Лицея](https://yandexlyceum.ru/). Это классическая игра "Pac-Man", реализованная на Python, с использованием базовых и продвинутых концепций программирования.

## О проекте

Игра "Pac-Man" — это аркадная игра, в которой игрок управляет персонажем, перемещающимся по лабиринту, избегая привидений и собирая очки. В данном проекте реализованы следующие функции:
- Управление персонажем с помощью клавиатуры.
- Привидения с уникальным поведением.
- Подсчет очков.
- Конечные условия игры (победа/поражение).

## Технологии

- Язык программирования: **Python**
- Используемые библиотеки:
  - `pygame` — для графики и обработки событий.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/GameTrue/PacManProject.git
   ```
2. Убедитесь, что у вас установлен Python 3.6 или выше.
3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите игру:
   ```bash
   python main.py
   ```
